# 📈 Stock Price Predictor

A simple machine learning web application that predicts the next closing price from historical stock data.

## 🚀 Features

- Upload stock data through CSV
- Select the price column
- Predict the next closing price
- USD and INR display options
- Linear Regression model
- MAE and R² evaluation
- Historical price visualization
- Download prediction results

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## 📊 Machine Learning

The application uses Linear Regression.

The model uses the previous price as the input feature and learns to predict the next price.

Previous Price → Linear Regression → Next Price
